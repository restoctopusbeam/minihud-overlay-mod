## 📖 About

MiniHUD Overlay is a configurable information HUD showing coordinates, biome, light level, slime chunks, spawn sphere, and dozens of other data lines in a compact corner panel.

---

## ✨ Features
<a name="features"></a>

- **60+ Data Lines** — pick exactly what to display.
- **Compact Mode** — minimal one-line summary for streaming.
- **Slime Chunk Overlay** — green tint on slime chunks.
- **Spawn Sphere** — 24 and 128 block sphere overlays.
- **Light Level Overlay** — colour-coded ground light.
- **Toggle Key** — show/hide the entire panel.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
